## 📞 TROUBLESHOOTING

### Node.js Not Installed
- Download from: https://nodejs.org/
- Or use: `brew install node` (macOS)
- Or use: `sudo apt install nodejs npm` (Linux/WSL)

### Port 3000 in Use
```bash
npm run dev -- --port 3001
```

### Module Errors
```bash
rm -rf node_modules
npm install
```

### TypeScript Errors
These are normal before `npm install`. They resolve after installation.
